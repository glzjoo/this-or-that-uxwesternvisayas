# Project PRD: DuoDecide (This or That)

## 1. Project Overview
**DuoDecide** (operating under the "This or That" brand) is an interactive voting platform designed to help users make decisions or learn design principles through A/B comparisons. The project is sponsored by **UX Western Visayas**, emphasizing educational value and high-quality UI/UX standards.

## 2. Target Audience
- UI/UX Designers and Students
- Product Managers
- General users looking for a fun, interactive way to compare options.

## 3. Core Features & Functionality

### 3.1. Interactive Voting Screen
- **Side-by-Side Comparison:** Two distinct options presented as cards with high-quality images and descriptive text.
- **Progress Tracking:** A visual progress bar and "Question X of Y" indicator to provide user orientation.
- **Skip Functionality:** A clear "Skip this question" action for users who cannot or do not want to decide on a specific pair.
- **Responsive Layout:** Optimized desktop views with multiple layout variants (Horizontal, Split, Stacked).

### 3.2. Branding & Identity
- **Dual Branding:** Co-branding between "UX Western Visayas" (Primary) and "This or That" (Product).
- **Visual Style:** Modern, minimalist, and professional.
- **Design Tokens:**
    - **Primary Color:** #7366ff (Vibrant Purple)
    - **Typography:** Hanken Grotesk (Sans-serif, clean, modern)
    - **Shape:** Rounded-md (8px radius) for cards and UI elements.

### 3.3. Navigation (Predicted)
- **Top App Bar:** Simple header containing the brand logos.
- **Bottom Navigation (Mobile):** Quick access to Home, Discover, Leaderboard, and Profile.

## 4. UI/UX Principles Applied
Based on Adobe's Design Principles research:
- **Readability:** High contrast between text and backgrounds; use of professional type scales.
- **Hierarchy:** Clear focal points on the comparison cards; prominent typography for the scenario question.
- **Usability:** Large, accessible hit areas for voting; consistent interaction patterns across screens.
- **Minimalism:** Removal of unnecessary UI clutter (e.g., sidebars, complex nav) to focus on the core voting task.

## 5. Design Assets
- **Logo:** Geometric "This or That" mark using the #7366ff palette.
- **Typography:** Hanken Grotesk via Google Fonts.
- **Images:** High-fidelity, relevant UI design comparisons.

## 6. Future Scope
- **Dark Mode:** A high-contrast dark theme variant.
- **Results Dashboard:** Post-vote analytics showing how others voted.
- **Community Poll Creation:** Tools for users to upload their own "This or That" scenarios.
- **Gamification:** Leaderboards and badges for consistent contributors.
